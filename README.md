# ไลฟ์อีกแล้ว! — Mouth Patrol

เกมจับจังหวะเว็บ แยกจาก Rat City และ Friday Rush ใช้ HTML, CSS และ JavaScript ธรรมดา ไม่ต้องติดตั้งแพ็กเกจ

## วิธีเล่น

1. เปิด `index.html` หรือรัน `python3 -m http.server 8000` ในโฟลเดอร์เกม แล้วเข้า `http://localhost:8000`.
2. รอคนหัวล้านไลฟ์เด้งเข้าจอ แล้วแตะหรือคลิกตรงปากเพื่อแปะพลาสเตอร์
3. ต้องกดให้ทันก่อนครบ 5 วินาที ถ้าพลาด 3 ไลฟ์ เกมจบ
4. ปิดปากทันจะได้คะแนนและคอมโบเพิ่ม คะแนนไหลต่อระหว่างที่ติดพลาสเตอร์
5. ใช้ปุ่มลำโพงเปิด/ปิดเสียงได้; บน iPhone ลากนิ้วไม่จำเป็น แตะตรงปากได้เลย
6. สถิติสูงสุดบันทึกในเบราว์เซอร์เครื่องนี้ ช่วงพักสุ่มกิจกรรมและสุ่มเวลาเร็ว/ช้า
7. ตั้งชื่อก่อนเล่นครั้งแรก เกมจำชื่อและรหัสผู้เล่นไว้ในเบราว์เซอร์ จากนั้นบันทึกคะแนนดีที่สุดของผู้เล่นคนนั้นขึ้นตารางอัตโนมัติ

ตัวละครกับคำพูดเป็นเรื่องแต่ง ภาพวาดและเสียงสังเคราะห์สร้างในเกม

หมายเหตุ: GitHub Pages เก็บคะแนนรวมข้ามเครื่องให้ทุกคนไม่ได้ คะแนนสถิติในเวอร์ชันนี้จึงเป็นสถิติในเบราว์เซอร์เครื่องนั้น หากต้องการตารางอันดับออนไลน์ที่ผู้เล่นทุกคนเห็นร่วมกัน ต้องเชื่อมฐานข้อมูลออนไลน์เพิ่ม

## เปิดตารางอันดับออนไลน์

GitHub Pages เป็นเว็บแบบ static จึงเก็บคะแนนรวมให้ทุกคนเองไม่ได้ เกมนี้เชื่อม Supabase ผ่าน REST API ได้:

1. สร้างโปรเจกต์ Supabase แล้วเปิด **SQL Editor**
2. วางและรันเนื้อหาใน `supabase-setup.sql` เพื่อสร้างตารางและนโยบายอ่าน/ส่งคะแนน
3. ใน **Project Settings → API Keys** คัดลอก **Project URL** กับ **publishable key** (โปรเจกต์เก่าอาจเรียกว่า `anon` key)
4. ใส่สองค่านั้นใน `supabase-config.js` ที่ `url` และ `publishableKey`
5. อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ขึ้น repository แล้วเปิด Pages ตามขั้นตอนด้านล่าง

หน้าเว็บเปิดเผย publishable/anon key ได้เมื่อจำกัดสิทธิ์ด้วย RLS ตาม SQL นี้ ห้ามนำ `service_role` หรือ secret key มาใส่ในไฟล์หน้าเว็บ เกมแสดง 20 อันดับและเก็บคะแนนดีที่สุดหนึ่งรายการต่อรหัสผู้เล่น รหัสนี้อยู่ในเบราว์เซอร์เครื่องเดิม; การล้างข้อมูลเว็บหรือเปลี่ยนเครื่องจะทำให้เกมจำเป็นผู้เล่นใหม่ ระบบชื่อเล่นไม่ใช่ระบบยืนยันตัวตนและยังอาจถูกปลอมคะแนนได้

## เผยแพร่ด้วย GitHub Pages

อัปโหลด `index.html`, `game.js`, `styles.css`, `supabase-config.js`, `supabase-setup.sql` และ `README.md` ไว้ที่ root ของ repository จากนั้นไปที่ **Settings → Pages** เลือก **Deploy from a branch → main → /(root) → Save**
